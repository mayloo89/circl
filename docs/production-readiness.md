## 3. Security Fixes (Critical)

### WebSocket origin validation
**File:** `backend/internal/chat/handler.go`

The WebSocket upgrader accepts connections from any origin. WebSocket upgrades bypass CORS middleware, so this must validate origins independently.

```go
// CURRENT (insecure)
CheckOrigin: func(_ *http.Request) bool { return true }

// REQUIRED: validate against allowed origins
CheckOrigin: func(r *http.Request) bool {
    origin := r.Header.Get("Origin")
    for _, allowed := range allowedOrigins {
        if origin == allowed { return true }
    }
    return false
}
```

### Database SSL
Ensure `DATABASE_URL` uses `sslmode=require` or `sslmode=verify-full` in production. Never use `sslmode=disable` outside of local dev.

### Rate limiting
Config variables exist (`RATE_LIMIT_REQUESTS`, `RATE_LIMIT_WINDOW`) but no middleware is implemented yet. Needs:
- [ ] Rate limiter middleware (per-IP on auth endpoints, per-user on API)
- [ ] WebSocket connection rate limiting
- [ ] Search endpoint throttling

### Token expiry
`main.go` hardcodes `tokenExpiry = 24 * time.Hour` instead of reading `JWT_EXPIRY` from env. Should respect the configured value.

## 4. Code Changes Required

### S3Storage implementation
**File:** `backend/cmd/api/main.go` (line ~113)

Currently only `STORAGE_PROVIDER=local` is wired. Need to:
- [ ] Implement `S3Storage` struct satisfying the `storage.Storage` interface
- [ ] Wire it in `main.go` when `STORAGE_PROVIDER=s3`
- [ ] Use pre-signed URLs for uploads (no file data through the backend)

### next/image remote patterns
**File:** `frontend/next.config.ts`

Currently hardcoded to `localhost:8080`. For production, add the S3/CDN hostname:

```ts
images: {
    remotePatterns: [
        {
            protocol: "https",
            hostname: "your-cdn.cloudfront.net", // or S3 bucket hostname
        },
    ],
},
```

### App metadata
**File:** `frontend/app/layout.tsx`

Still has placeholder values:
```ts
// CURRENT
title: "Create Next App",
description: "Generated by create next app",

// REQUIRED
title: "Circl",
description: "Private contact platform with secure chat",
```

### NextAuth cookie security
**File:** `frontend/lib/auth.ts`

Verify that NextAuth production defaults apply:
- `secure: true` (HTTPS only)
- `httpOnly: true`
- `sameSite: "lax"`

NextAuth handles this automatically when `NEXTAUTH_URL` uses `https://`, but worth verifying.
